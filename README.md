## Documentation For Authorization


Authentication schemes defined for the API:
<a id="bearerAuth"></a>
### bearerAuth

- **Type**: Bearer authentication (JWT)

<a id="oauth2"></a>
### oauth2

- **Type**: OAuth
- **Flow**: accessCode
- **Authorization URL**: https://api.cloudbeds.com/auth/oauth/authorize
- **Scopes**: 
 - **read:reservation**: Read fiscal documents and fiscalization configuration
 - **write:reservation**: Create, update, or void fiscal documents and fiscalization configuration
